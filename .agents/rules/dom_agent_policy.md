# DOM Agent & Browser Subagent Usage Policy

## Mandatory Requirement: Explicit User Permission
- **Do not automatically launch or use the DOM Agent / Browser Subagent (`browser_subagent`)**.
- Whenever browser automation or DOM inspection using the browser agent is considered or needed:
  1. Clearly explain to the user **why** the browser / DOM agent is needed and **what** actions it will perform.
  2. Ask for explicit permission / confirmation from the user.
  3. Wait for the user's explicit approval before triggering any browser or DOM subagent tools.
